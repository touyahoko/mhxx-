# MHXX 頑シミュ (Android版)

モンスターハンターダブルクロス 装備シミュレータの Android 移植です。

元アプリ「頑張って作ったモンハンシミュレータ for MHXX ver.0.9」の主要機能を移植しています。

## 機能

| 機能 | 状態 |
|------|------|
| データ読込（装備5部位・スキル・装飾品・お守り・conf） | ✅ |
| ダークUI（HTMLツール準拠） | ✅ |
| スキル選択（系統フィルタ） | ✅ |
| 装備組み合わせ探索 | ✅ |
| 装飾品自動配置（貪欲法） | ✅ |
| お守り選択・検索反映 | ✅ |
| 除外装備 | ✅ |
| 固定装備 | ✅ |
| 装飾品除外 | ✅ |
| 剣士/ガンナー切替 | ✅ |
| マイセット保存・読込・固定反映 | ✅ |

## 使い方

1. **シミュレータ** … 発動スキルをタップ選択 → 検索
2. **除外装備** … 使わない装備をタップで除外
3. **固定装備** … 必ず入れる装備を部位ごとに固定
4. **装飾品除外** … 使わない珠を除外
5. **お守り** … 検索に使うお守りを選択
6. **マイセット** … タイトルタップで直近検索結果を保存

ヘッダーの **両方 / 剣士 / ガンナー** チップで装備タイプを絞り込みます。

## ビルド

GitHub Actions で `main` push 時に APK を生成します。

```bash
./gradlew assembleDebug
# app/build/outputs/apk/debug/app-debug.apk
```

## 制限・今後

- 装飾品配置は貪欲法のため、元デスクトップ版より最適解を逃す場合あり
- 元アプリの全探索アルゴリズム・全UI細項目の完全再現ではない
- 複合スキル・特殊条件の一部は未対応の可能性あり
