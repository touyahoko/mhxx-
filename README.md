# MHXX 頑シミュ (Android版)

モンスターハンターダブルクロス 装備シミュレータのAndroid移植プロジェクトです。

## 現状

| 機能 | 状態 |
|------|------|
| データ読み込み (装備/スキル/装飾品/お守り) | ✅ |
| タブUI (HTML準拠ダークテーマ) | ✅ |
| スキル一覧・選択 | ✅ |
| 装備組み合わせ探索 | ✅ |
| 除外装備の検索反映 | ✅ |
| 固定装備の検索反映 | ✅ |
| 装飾品除外 | ✅ |
| マイセット保存 | ✅ |

## 使い方

1. **シミュレータ** … 発動したいスキルをタップで選択 →「検索」
2. **除外装備** … 使いたくない装備をタップで除外（検索から外れる）
3. **固定装備** … 必ず入れたい装備を部位ごとに固定
4. **マイセット** … タイトルをタップで直近の検索結果を保存

## ビルド

GitHub Actions: `main` push で APK 生成 → Artifacts からダウンロード

```bash
./gradlew assembleDebug
```
